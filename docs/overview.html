Loslegen in fünf Schritten

Vom Quellcode bis zum ersten Board im Browser.

1
Bauen
go build -o bin/kard \ ./cmd/kard
Braucht Go 1.27. Danach bin/kard in den PATH legen.
2
Nachsehen, wer man ist
kard whoami angelique.lambert@firma.de (from git config user.email)
Nichts einzurichten: Der Name kommt aus Git, je Repo. Ein eigener mit kard whoami --set.
3
Board anlegen
cd ~/Repos/projekt kard init board
Schreibt die board.yaml und meldet das Board an.
4
Weitere Boards finden
kard scan ~/Repos kard boards
Sucht dauerhaft nach board.yaml, sechs Ebenen tief.
5
Arbeiten
kard ui kard new "Login prüfen" kard take login-pruefen
Browser und Terminal wirken gleich, mit denselben Regeln.
kard init · leerer Ordner
board/ (leer)
→
board/ board.yaml backlog/ working_on/ doing done/ done
Drei Spalten als Vorgabe. Eigene mit --columns a,b,c.
kard init · vorhandene Notizen
notizen/ ideen/*.md wip/*.md closed/*.md
→
notizen/ board.yaml ideen/ wip/ doing closed/ done
Ordner werden Spalten. Keine Datei wird verändert. Was nicht passt, zeigt danach kard lint.

Drei Stufen Git

Eine Zeile in board.yaml entscheidet.

sync: none
Board im Code-Repo. Committen tut man selbst.
sync: commit
Eigenes Board-Repo, allein.
sync: push
Board-Repo im Team. Wer zuerst pusht, gewinnt; der andere erfährt, wo die Karte jetzt liegt.
